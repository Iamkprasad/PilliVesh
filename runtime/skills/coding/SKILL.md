# Coding Skill

## Purpose
Solve programming tasks systematically while minimizing unnecessary context.

## Activate When
- Writing code
- Modifying existing code
- Debugging implementation logic
- Reviewing code

## Workflow
1. Understand the requested behavior.
2. Inspect relevant files before changing anything.
3. Identify the smallest correct change.
4. Implement the change.
5. Run an appropriate test or validation.
6. Inspect failures and correct them.
7. Report what changed and what was verified.

## Rules
- Prefer small, reversible changes.
- Do not modify unrelated files.
- Do not assume a file's contents without inspecting it.
- Verify important changes rather than relying on reasoning alone.

## Verification
A coding task is not considered complete until the relevant implementation has been tested or explicitly verified.
